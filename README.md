# First PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow: clone, branch, commit, push, open a PR.

## What this is

This repo starts nearly empty on purpose. The goal is to make a small, safe change — a typo fix, a wording tweak, a missing detail — and ship it as a real pull request from start to finish.

## Getting Started

1. Clone the repo
2. Create a branch
3. Make your change
4. Open a pull request

Feel free to keep useing this repo for future practice PRs.
